# Apparatus — Archival Locators

Read for the `historical-archival` variant and whenever unpublished documents are cited.

- Locator format: repository → collection or fonds → series → box or volume → folder or folio → item, using the repository's own reference codes. Add the document's date of production and, if different, date of the copy inspected.
- Record whether the item was inspected in the original, in a digital surrogate, in a published edition, or only through a finding aid. Finding-aid access is `metadata-only`.
- Do not normalize spelling or expand abbreviations silently; mark editorial interventions in brackets.
- Citation styles differ; follow the selected `references/citation/` file for note and bibliography forms, keeping the repository's reference code intact.
