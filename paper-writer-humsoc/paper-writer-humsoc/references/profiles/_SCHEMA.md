# Profile Schema

Every profile file follows these twelve items in this order, with these exact headings. SKILL.md refers to them by number ("profile §5"). Keep §1–§12 under ~4 KB; the variant table is extra. Detail that does not fit belongs in an apparatus file.

Copy this file to start a new profile. Replace every `<...>`.
