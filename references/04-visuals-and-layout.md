# Visuals and Layout

Visuals are optional. Add one only when it materially clarifies a relationship or presents primary evidence prose cannot adequately convey.

Suitable forms include a sourced timeline, concept genealogy, debate map, relation map among texts or editions, comparison table, rights-cleared source image, or analytically relevant map. Do not add quantitative plots, heatmaps, model architectures, equations, or decorative diagrams to satisfy a count. Do not convert interpretive judgments into scores without an explicit, transparent coding framework requested by the user.

For every image or facsimile, record source, creator, date, holding institution or publication, identifier, rights status, and modifications. Captions must distinguish description from interpretation. Every timeline date and relationship edge maps to `evidence_ledger.md`; label interpretive relations as interpretation.

Use tables for exact comparison, not long prose. Include a caption, column labels, source notes, and a label referenced in text. Avoid turning contested concepts into false equivalences.

Use relative paths under `figures/`. Reference every visual in prose. The default DOCX should use editable captions and accessible alt text when supported. Check rendered DOCX pages and the PDF for clipping, illegible text, orphan headings, widows, broken notes, and malformed non-Latin characters.

LaTeX-specific layout rules apply only when LaTeX was requested. Use a Unicode-capable engine for non-Latin scripts and verify glyphs visually.
