# Genre files

Read the file named in `project_manifest.md` (`genre:`). The default (no file) is a journal-article-style research report following the profile's §6 structure. Planned: `journal-article.md`, `thesis-chapter.md`, `institutional-report.md`, `policy-brief.md`, `research-proposal.md`, `review-essay.md`. Each genre file adjusts length, abstract form, inclusion of recommendations, and appendices; it never changes evidence rules.
