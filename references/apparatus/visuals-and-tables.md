# Apparatus — Visuals and Tables (general)

Read when a comparison table, timeline, concept map, or debate map is used.

- Suitable forms: sourced timeline, concept genealogy, debate map, relation map among texts or editions, comparison table. Not suitable: quantitative plots without data, scores derived from interpretive judgments, decorative diagrams.
- Tables are for exact comparison, not long prose. Each has a label referenced in the text, a caption, column headers, and a source note. Do not turn contested concepts into false equivalences.
- Every timeline date and every edge in a relation map maps to an `evidence_ledger.md` row; interpretive relations are labeled "interpretation".
- Captions separate description ("the table lists") from interpretation ("this suggests").
- DOCX: editable captions, accessible alt text when supported. Check rendered pages for clipping, orphan headings, and malformed non-Latin characters.
