# Citation — generic author-date (default)

- In-text: (Author Year, locator). Multiple works: (Author Year; Author Year). Same author and year: a, b suffixes.
- Reference list: alphabetical by author, then year. Include editor, translator, edition, and original publication date where relevant; separate primary and secondary lists only if the genre or user requests it.
- Notes are for substantive comment, not for citations.
- Render from `bibliography.json`; do not hand-type entries. Non-Latin titles keep the original script with a bracketed translation.
